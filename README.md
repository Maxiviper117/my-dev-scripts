# my-dev-scripts

A collection of personal development scripts, setups, and configurations for streamlining development workflows across various technologies and environments.

## Purpose

This repository serves as a centralized hub for:
- **Setup scripts**: Bootstrap new machines or environments with essential tools and configurations
- **Framework helpers**: Specialized scripts for popular frameworks like Laravel, SvelteKit, and Effect-TS
- **Docker utilities**: Containerization scripts and compose files for local development
- **Git tools**: Aliases and cleanup scripts for version control management
- **Editor configurations**: Dotfiles and settings for VS Code, Neovim, and terminal environments
- **General utilities**: One-liners and scripts for common development tasks
- **Documentation**: Guides, notes, and setup instructions

## Organization

Scripts are organized by domain to make them easy to find and maintain:
- `setup/`: Environment bootstrapping
- `frameworks/`: Framework-specific automation
- `docker/`: Containerization tools
- `git/`: Version control helpers
- `editors/`: IDE and editor configs
- `utils/`: General-purpose scripts
- `docs/`: Documentation and guides
